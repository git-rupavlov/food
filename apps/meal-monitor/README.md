# Meal Monitor

Starter web app for food and nutrient intake monitoring.

## Scope

- USDA FoodData Central food search
- grams-based nutrient calculation
- per 100 g and per selected quantity views
- nutrient cart totals
- digestible carbohydrate estimate
- future daily, weekly and monthly dashboards
