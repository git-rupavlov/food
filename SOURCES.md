# Project Focus

This project prioritizes:

- physiology
- biochemistry
- microbiology
- food chemistry
- thermodynamics
- evidence-based nutrition
- practical cooking

instead of:
- influencer nutrition
- detox marketing
- miracle food mythology
- social media performance nutrition

Because food is:
- biology
- chemistry
- physics
- microbiology
- agriculture
- adaptation

Not:
- cinematic avocado propaganda with motivational background music.
