# Домашна кухня: физика, химия и физиология на храната

## Основен принцип

Храната не е само:
- калории
- протеин
- мазнини
- въглехидрати

Тя е:
- биохимична система
- микробиологична среда
- термодинамичен процес
- структура от протеини, мазнини, вода и минерали

При:
- рязане
- печене
- варене
- ферментация
- сушене

ние променяме:
- молекулите
- ензимите
- окислението
- структурата
- бионаличността

---

## Денатурация

Промяна в структурата на:
- протеини
- ензими
- мембрани

Предизвиква се от:
- температура
- киселини
- сол
- механично въздействие

Пример:

```text
albumin
  + heat
  ->
denaturation
  ->
coagulation
```

---

## Окисление

Реакция между:
- кислород
- нестабилни молекули

Засега:
- PUFA мазнини
- витамин C
- каротеноиди
- полифеноли

Процес:

```text
unsaturated fat
  + O2
  ->
lipid radicals
  ->
peroxides
  ->
aldehydes
```

Резултат:
- гранясали мазнини
- oxidative stress
- деградация

---

## Maillard реакции

Реакция между:
- аминокиселини
- редуциращи захари

Температура:
- ~120-180C

Получават се:
- меланоидини
- ароматни молекули
- pyrazines

Прекомерно:
- AGEs
- acrylamide
- carbonization

---

## Лук

Основни вещества:
- sulfur compounds
- quercetin
- inulin
- fructooligosaccharides

При рязане:

```text
alliinase
  + sulfur precursors
  ->
thiosulfinates
  ->
volatile sulfur compounds
```

При термична обработка:
- намалява острият вкус
- увеличава се сладостта
- протичат Maillard реакции

---

## Зеле

Съдържа:
- glucosinolates
- vitamin C
- sulfur compounds
- fiber

```text
glucosinolates
  + myrosinase
  ->
isothiocyanates
  ->
sulforaphane
```

Оптимална обработка:
- кратка пара
- леко задушаване
- stir fry

---

## Ферментация на зеле

```text
Lactobacillus spp.
  ->
lactic acid
  ->
lower pH
```

pH:
- ~3.5-4.0

Следствия:
- стабилизация
- по-малко патогени
- по-дълъг shelf life

---

## Моркови

Основно:
- beta-carotene

```text
heat
  ->
pectin softening
  ->
cell wall breakdown
  ->
carotenoid release
```

Нужни са:
- липиди
- жлъчни соли
- micelles

Добри комбинации:
- морков + масло
- морков + зехтин

---

## Броколи / Карфиол

```text
glucoraphanin
  + myrosinase
  ->
sulforaphane
```

Оптимум:
- кратка пара
- леко задушаване
- ~60-85C

---

## Домати

Основно:
- lycopene

```text
heat
  ->
cell wall breakdown
  ->
trans -> cis isomerization
  ->
higher bioavailability
```

Добра комбинация:
- домати + зехтин

---

## Цвекло

```text
NO3-
  ->
NO2-
  ->
Nitric Oxide
```

NO участва в:
- вазодилатация
- blood flow
- mitochondrial signaling

---

## Спанак

Съдържа:
- folate
- magnesium
- vitamin K

Oxalic acid:
- образува calcium oxalate

Леко варене:
- намалява част от оксалатите

---

## Орехи

Съдържат:
- omega-3 ALA
- polyphenols

```text
PUFA
  + O2
  ->
peroxides
  ->
aldehydes
```

Добро съхранение:
- тъмно
- хладно
- цели ядки

---

## Зехтин

Основно:
- oleic acid

Polyphenols:
- hydroxytyrosol
- oleuropein

Важно:
- smoke point != stability

---

## Слънчогледово олио

Високо:
- omega-6 PUFA

```text
heat
  + oxygen
  + PUFA
  ->
lipid oxidation
```

Особено лошо:
- многократно пържене

---

## Краве масло

Съдържа:
- saturated fat
- butyrate

```text
milk solids
  + heat
  ->
Maillard reactions
  ->
carbonization
```

## Кисело мляко

```text
Lactobacillus bulgaricus
  +
Streptococcus thermophilus
  ->
lactic acid
```

- lactose breakdown
- по-добра смилаемост

collagen

## Финална логика

Силната домашна кухня:
- използва сезонни продукти
- разбира окислението
- използва ферментация
- минимизира разрушаването на вещества
- комбинира мазнини с мастноразтворими молекули
- използва целия продукт

Храната е:
- биохимия
- физика
- микробиология
- физиология

Не само:
- калории
- маркетинг
- "detox ultra bowls"
